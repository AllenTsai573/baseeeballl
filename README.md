# 野球日和

以滑鼠操作的棒球打擊練習遊戲。使用純 HTML、CSS 與 JavaScript，可直接在瀏覽器執行。

## 開始遊戲

- 線上版（開啟 GitHub Pages 後）：https://allentsai573.github.io/baseeeballl/
- 離線版：下載 `index.html`，使用 Edge 或 Chrome 開啟，不需要安裝套件或架設伺服器。

## 操作

- 滑鼠移動：移動擊球棒身。
- 滑鼠左鍵：完整揮棒；沒有來球時可試揮。
- 空白鍵：開始／再次投球；投球或揮棒進行中不會重複投球。
- 球場內也保留「開始投球」和「試揮」按鈕。
- 中央來球可將球棒位置選為「固定中央」，專心練習時機。
- 觸控：拖曳移動棒身、輕點揮棒。

可選直球、滑球、曲球與指叉球，調整球速、揮速及揮棒上揚角。揮空會提示太早、太慢或位置偏離。自由練習不計好壞球和出局。

## 效能與落點

場景、棒身圖示和落點軌跡採快取；畫面會顯示實際 FPS。更新率依裝置、瀏覽器與螢幕而異。擊球初速、仰角、方向及首次落地位置使用簡化物理模型估算，並非經實測校準的模擬器。

## GitHub Pages 設定

在此儲存庫的 **Settings → Pages**：

1. Source 選擇 **Deploy from a branch**。
2. Branch 選擇 **main**，資料夾選擇 **/ (root)**。
3. 按下 **Save**，等候網站部署完成。
